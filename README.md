# NetSuite OAuth 2.0 RESTlet guide

Step-by-step guide for connecting an external app to a NetSuite RESTlet with
OAuth 2.0 client credentials (machine to machine), with code in several languages.

- `index.html`: the interactive guide, served by GitHub Pages.
- `guide.md`: the same guide as Markdown, for AI agents.
- `.nojekyll`: stops GitHub Pages running Jekyll, so `guide.md` is served as raw Markdown.

Enable Pages under **Settings > Pages > Build and deployment**: Source *Deploy from a branch*,
branch `main`, folder `/ (root)`.
